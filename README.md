## 说明

- 立绘为"身体层 + 表情碎片"分层结构，部分立绘面部为空白，需配合表情碎片合成（表情碎片为角色目录内的小尺寸 PNG）。
- 事件 CG 为图层碎片（pimg 拆层结果），如需成图需按 cglist 配方合成。
- 语音（voice）、视频（video）及成人内容（R18）不在本仓库。
- 文件名包含日文，Windows 下克隆需开启 `core.longpaths`。
