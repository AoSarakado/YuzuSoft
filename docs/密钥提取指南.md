# GARbro 密钥提取指南（柚子社系）

从 GARbro 的 Formats.dat（GARbroDB 数据库）dump 出游戏的 xp3 解密密钥，
生成 GARbro 密钥 txt 文件（本仓库 keys/ 目录的格式）。

## 背景

- 密钥数据在 **fork/mod 的 GameData/Formats.dat**（GARbroDB 二进制），**不在源码**
  （YuzCrypt.cs 等源码 grep 游戏名必空）。
- `Xp3Opener.KnownSchemes` 运行时从 Formats.dat 反序列化出所有加密方案，
  用反射工具 dump 字段即得密钥参数（m_mask/m_offset/PrologOrder/OddBranchOrder/
  EvenBranchOrder/ControlBlock[1024]/YuzKey/m_key1/m_key2 等）。
- GARbro-Mod（crskycode）的 Formats.dat 已收录柚子社多作：
  Cafe Stella、Riddle Joker、Dracu-Riot!、Senren★Banka（千恋万花）、
  Limelight Lemonade Jam（2025 新作，中文圈常叫"柠檬工厂"）、Sanoba Witch 等。

## 步骤

### 1. 工具源码

`tools/dump_garbro_keys.cs`（本仓库）——反射 dump 模板，已含：
- ControlBlock 完整输出 1024 个值（`Take(40)` 截断会丢密钥）
- yuzu 系关键字过滤（Riddle/Stella/Senren/Cabbage/Nana/Dracu/Limelight）

编译（csc，.NET Framework）：
```bash
cd <GARbro mod 目录>
"C:/Windows/Microsoft.NET/Framework64/v4.0.30319/csc.exe" /nologo \
  /out:DumpGarbroKeys.exe \
  /r:GameRes.dll /r:ArcFormats.dll /r:System.Text.Encoding.CodePages.dll \
  dump_garbro_keys.cs
```
- 坑：`/r:ArcFormats.dll.config` 报 CS0009（config 不是程序集），别引用 .config
- exe 必须和 GameData/Formats.dat 同目录运行

### 2. 运行

```bash
./DumpGarbroKeys.exe > dump.txt 2>&1
grep -a "^===" dump.txt    # 方案列表（含非 UTF-8 标题，grep 需 -a）
```
输出每段：`=== 游戏名 -> GameRes.Formats.KiriKiri.xxxCrypt ===` + 字段行。

### 3. 生成密钥 txt

格式（同 keys/ 目录已有文件）：
- 每行 `字段=值`，去掉 dump 的缩进与方括号
- 基类字段加 `base_` 前缀
- 数组 `[0x.., 0x..]` → 去括号、逗号分隔无空格

解析注意：
- **CRLF 坑**：re.split 切段时 `\r` 挡在 `===` 和 `$` 之间 → 先 `replace('\r\n', '\n')`
- **★ 乱码坑**：ISO-8859-1 解码下 Senren★Banka 的 ★ 变乱码 → 按类型（SenrenCxCrypt）匹配
- **Sanoba Witch** 是 YuzuCrypt 通用加密，无独立参数（dump 只有两行 base bool）——
  密钥文件只需注释说明"通用加密，用 GARbro 内置支持即可"

### 4. 验证

- 密钥文件里 ControlBlock 逗号分割数 == 1024（CxEncryption 等简单方案无 ControlBlock，属正常）
- 实测产物：Riddle_Joker(+Steam)、Dracu_Riot(+Steam)、Senren_Banka、Limelight_Lemonade_Jam、Sanoba_Witch
