# Yuzu-Soft（柚子社）游戏解包指南

本指南基于《星光咖啡馆与死神之蝶》（Cafe Stella to Shinigami no Chou）完整解包流程整理，
适用于柚子社同引擎作品（Riddle Joker / Dracu-Riot! / 千恋万花 / Limelight Lemonade Jam / Sanoba Witch 等）。

## 1. 工具链

| 工具 | 用途 | 来源 |
|------|------|------|
| GARbro（Mod 版） | xp3 解包 / pimg 拆层 | crskycode/GARbro-Mod release |
| arc_unpacker | tlg → png 转换 | 开源，支持 kirikiri/tlg |
| GARbro.Console.exe | 命令行解包 | GARbro 自带 |
| keys/ 目录 | 各游戏 xp3 解密密钥 | 本仓库（GARbro 社区数据库提取） |

## 2. 密钥原理

柚子社新作（2018 后）xp3 使用自研加密（RiddleCxCrypt / SenrenCxCrypt / HxCrypt 等），
GARbro 的密钥**不在源码**，而在 `GameData/Formats.dat`（GARbroDB 序列化数据库，zlib 压缩 + .NET BinaryFormatter）。

- 官方 GARbro（morkt）部分作品未收录（如 Cafe Stella，issue #396 长期 open）
- 社区 fork（crskycode 等）的 Formats.dat 收录更全
- 提取方法：csc 编译反射工具，加载 Formats.dat → 反序列化 → 反射 dump scheme 字段
  （YuzKey[6] / ControlBlock[1024] / m_mask / m_offset / PrologOrder / OddBranchOrder / EvenBranchOrder）

密钥文件格式（keys/*.txt）：
```
m_key1=2863311530
m_key2=1431655765
YuzKey[6]=0x9E8F879A,0xCCDF9B91,...
m_mask=280
m_offset=271
PrologOrder=0x00,0x01,0x02
OddBranchOrder=0x02,0x05,0x03,0x04,0x01,0x00
EvenBranchOrder=0x00,0x02,0x03,0x01,0x05,0x06,0x07,0x04
ControlBlock[1024]=0xBE811241,0x931DB3BB,...（完整 1024 个）
```

## 3. 解包流程（xp3 → 文件）

```bash
# 批量解包（GARbro.Console 提取到当前工作目录）
GARbro.Console.exe -x "游戏目录\evimage.xp3"
```

- GARbro.Console 按文件名自动匹配游戏密钥（LookupGame）
- 全部 11 个 xp3：main / data / scn / bgimage / evimage / fgimage / bgm / voice / video / uipsd / patch
- patch.xp3 = 汉化补丁内容（按使用边界不整理不公开）
- Windows 下注意：中文/日文路径用 MSYS 会出编码问题，尽量用原生 Windows 路径

## 4. 图片格式转换

### tlg → png（立绘 / 背景 / 图层）
```bash
arc_unpacker.exe "目标.tlg"   # 输出到当前目录，同名 .png
```
- kirikiri/tlg 解码器批量转换零失败
- 立绘 tlg 命名：`角色a_0_编号.tlg`（a=衣装差分，编号=资源 ID）
- 标准立绘尺寸约 508x1725 / 843x1769；另有 2x 高清大图（1686x3538）

### pimg → tlg（事件图容器拆层）
```bash
GARbro.Console.exe -x "ev101a.pimg"   # 输出内嵌 tlg 到 cwd
```
- pimg 是 PSB 容器（魔数 50 53 42 00 "PSB\0" v3）
- 拆出的 tlg 再用 arc_unpacker 转 png
- 事件图是图层碎片，完整 CG 需按 cglist 配方合成（基础图 + 差分图层叠加）

## 5. 立绘结构

- `fgimage/角色目录/`：身体层（空脸，含衣装）+ 表情碎片（眉毛/眼睛线条小图）+ 装饰
- 身体层面部为空白，**完整立绘 = 身体层 + 表情碎片合成**
- sinfo 文件（UTF-16LE）定义衣装/表情清单（dress 裸/私服/メイド服...、face 21 基本表情...）
- stand 文件定义立绘块位置（xoffset/yoffset）
- face id → 表情碎片映射在 pbd（TJS/4s0 加密字节码），运行时合成

## 6. 文本提取（PSB 编译脚本）

scn 文件是 PSB v3 编译容器，字符串表在文件后段：
- **UTF-8 明文**（不是 UTF-16LE），`\x00` 分隔
- 字符串表按 UTF-8 字节序排序（非演出顺序）
- BGM 引用：小写 `bgm01` / `bgm_BGM03`
- 语音引用：`角色缩写3字母 + 场景号 + 序号`（如 kan108_001）
- 背景引用：文件名明文（小写，如 マンション_主人公部屋a）
- 台词/旁白/演出注释标记：「」=台词、▽=演出注释、★=特效

## 7. 已知坑

1. **文件名含单引号**（BGM11_I'm Busy!）会破坏 ffmpeg concat 列表解析 → 先复制到临时序号名
2. **concat demuxer 图片轮播时间戳跳变**（41/42 视频中招）→ 改用 concat filter
   （每图独立 `-loop 1 -framerate 30 -t 6` 输入）
3. **scn 引用小写 vs 文件大写**（マンション_主人公部屋a vs A.png）→ 匹配忽略大小写
4. **sinfo 是 UTF-16LE**，pbd 是加密 TJS 字节码（无法直接读）
5. **Windows 长路径** → git core.longpaths true
6. **GitHub 直连被墙** → 系统代理；GARbro fork 的 release 要搜 fork 不是官方
7. **Formats.dat 是二进制**（GARbroDB 魔数）→ 用反射工具 dump，不能 grep

## 8. 版本区分

- 民间版（日文原版）：RiddleCxCrypt / SenrenCxCrypt 等
- Steam 版：HxCrypt（参数不同，密钥文件分开）
- 解包前确认游戏版本，用对应密钥
