# skills/

与游戏解包/逆向相关的 Hermes skill（来自本机 Hermes-Skills 仓库，随 YuzuSoft 仓库同步一份，便于解包工作流自包含）。

- game-asset-extraction — 解包游戏/提取资源五阶段工作流（引擎识别→解包→转换→分类→输出，TA 向）
- ida-mcp-setup — IDA Pro MCP 接入 Hermes 的配置与用法
- ida-reversing — 逆向分析/查找加密密钥/IDA MCP 实操

每个 skill 目录含 `SKILL.md`（及可能的 references/ 辅助文件）。
复制到 `HERMES_HOME/skills/` 对应分类下即可使用。

与 `docs/解包指南.md`、`docs/密钥提取指南.md`、`keys/`、`tools/` 配合使用。
